Open Heavy Machinery

Deterministic plant simulation, Hardware-in-the-Loop (HIL), and embedded control tooling for industrial, off-highway, and marine powertrain systems.

// Mission

Developing embedded control software for heavy machinery is bottlenecked by physical access. Real engines, dynamometer cells, and proprietary HIL rigs are expensive and inaccessible to independent engineers, researchers, and small teams.

Open Heavy Machinery builds open, auditable simulation and validation tools so control firmware can be developed, tested, and broken in CI or on a bench before touching physical iron.

// Active Projects

open-crank PRE-ALPHA · v0.1 TARGET

Open-source HIL/SIL heavy-duty engine plant simulator for critical embedded systems. Speaks SAE J1939 over CAN, decouples deterministic plant physics from I/O and time backends, and targets both soft real-time emulators (Renode, QEMU) and hard real-time FPGA rigs.

Honest status: the repository currently holds a README and a license. Nothing runs yet. v0.1 is the first milestone with something to execute.

// Roadmap

Scope is deliberately narrow at the start. Each milestone is small enough to finish and big enough to be useful on its own.

  • v0.1 — Vertical slice: mean-value model of the Liebherr D936L A6, one ECU in Renode, vcan, six PGNs, dashboard, one CI test that closes a speed-control loop.
  • v0.2 — Aftertreatment: DOC / DPF / SCR with soot and DEF dosing, regeneration request logic.
  • v0.3 — Fault injection: sensor open / short / plausibility, CAN dropout, limp-home paths.
  • v0.4 — HIL: FPGA time backend, real crank and cam waveforms, jitter measurement.
  • v0.5 — Second plant: MAN B&W 9G95ME-C10.6, propeller load, ME-style electronic control, PMS scenario. Refactor whatever the second plant breaks.

// Engineering Principles

SIL/HIL Parity

The plant model core never knows whether it is running in a CI pipeline or on an FPGA rig.

General Abstractions

Architectures will be validated across radically different plants, from 4-stroke crane diesels to 60 MW 2-stroke marine engines.

Permissive & Auditable

Licensed under Apache-2.0, including the patent grant. Protocol implementations are original, readable, and open to inspection.
